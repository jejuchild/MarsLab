## Implementation Notes

### Chart Data Flow
```
RegolithResult.profile[] contains RegolithSample objects
  ↓
chartData mapping filters interface_detected and extracts visualization fields
  ↓
ComposedChart renders:
  - Main thickness Area (blue #4f9cf7)
  - Epsilon uncertainty Areas (light blue #6fb5fb) [conditional on epsilon_uncertainty > 0]
  - Confidence Line (orange #f59e42) [dashed]
  - Custom Tooltip showing all fields
```

### State Management
```
User changes parameters in Advanced Parameters section
  ↓
State setters update: mode, epsilonUncertainty, clutterMode, snrThreshold, searchLo, searchHi
  ↓
paramsChanged computed from lastRunRef comparison
  ↓
If paramsChanged, show "Re-run Analysis" button
  ↓
Button click calls runAnalysis() which fetches new data from API
  ↓
API call includes all parameters in URL query string
  ↓
Result state updated, chart re-renders with new data
```

### Error Handling
All frontend API calls have try-catch in runAnalysis():
- Success: Update result state, update lastRunRef
- Error: Set error message, display in error box
