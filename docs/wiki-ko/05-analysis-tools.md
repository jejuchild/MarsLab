# 분석 도구 (Analysis Tools)

MarsLab은 4가지 지형/데이터 분석 도구를 제공합니다. 좌측 패널 **Analysis Tools** 섹션에서 원하는 모드를 선택합니다.

---

## Slope Analysis (경사 분석)

MOLA DEM 기반으로 지정 지점 주변의 경사도를 분석합니다. 로버 착륙지 적합성 평가에 활용됩니다.

### 사용법
1. 좌측 패널에서 **Slope Analysis** 버튼 클릭 (파란색)
2. 지도에서 분석할 지점 클릭
3. 우측 패널에 경사 분석 결과 표시

### 출력 정보

| 항목 | 설명 |
|------|------|
| 중심 좌표 | 클릭한 위도/경도 |
| 분석 반경 | 기본 1,000m (조절 가능) |
| Mean Slope | 평균 경사도 (도) |
| Max Slope | 최대 경사도 (도) |
| Elevation | 해당 지점의 고도 (m) |
| Pixel Count | 분석에 사용된 DEM 픽셀 수 |

### Safety Rating (안전성 등급)

경사도 분포에 따른 로버 안전성 평가:

| 등급 | 색상 | 기준 |
|------|------|------|
| **FAVORABLE** | 초록 | 대부분 0~3도 (안전) |
| **MARGINAL** | 노랑 | 3~5도 구간이 다수 (한계) |
| **UNFAVORABLE** | 빨강 | 5도 이상이 다수 (위험) |
| **UNKNOWN** | 회색 | 데이터 부족 |

### 경사도 분포 히스토그램
- 0~3도 (안전): 녹색 바
- 3~5도 (한계): 노란색 바
- 5도 이상 (위험): 빨간색 바

## Slope 3D (3D 지형 시각화)

선택한 지점 주변의 3D 지형 메시를 Three.js로 렌더링합니다.

### 사용법
1. 좌측 패널에서 **Slope 3D** 버튼 클릭 (보라색)
2. 지도에서 관심 지점 클릭
3. 해당 지점 주변의 DEM 데이터를 로드하여 3D 메시 생성

### 조작법
- **좌클릭 드래그**: 회전
- **우클릭 드래그**: 팬 (이동)
- **스크롤**: 줌 인/아웃
- 색상: 고도에 따른 컬러맵 (낮은 곳 파랑 → 높은 곳 빨강)

### HiRISE DTM 연동
- HiRISE DTM이 있는 영역에서는 MOLA 대신 **고해상도 DTM**을 사용
- 1m/px 급 정밀 지형 시각화 가능

## Line Profile (고도 프로파일)

두 지점 사이의 고도 변화를 그래프로 표시합니다.

### 사용법
1. 좌측 패널에서 **Line Profile** 버튼 클릭 (에메랄드색)
2. 지도에서 **시작점** 클릭
3. 지도에서 **끝점** 클릭
4. 두 점 사이의 고도 프로파일 차트 표시

### 출력 정보
- **프로파일 차트**: X축 = 거리(km), Y축 = 고도(m)
- **시작점/끝점 좌표**: 위도, 경도
- **최대 고도차**: 프로파일 내 최대~최소 고도 차이
- **평균 경사도**: 전체 구간의 평균 기울기

### 특징
- Recharts 기반 인터랙티브 차트
- 마우스 호버 시 해당 지점의 정확한 고도값 표시
- 이미지 다운로드 기능

## AI Analysis (AI 분석) — BETA

Google Gemini AI를 활용한 자동화된 영역 분석입니다.

### 사용법
1. 좌측 패널에서 **AI Analysis** 버튼 클릭 (바이올렛색)
2. 지도에서 분석할 지점 클릭
3. **분석 반경** 선택 (1km / 5km / 10km / 20km)
4. 자동으로 주변 데이터 수집 시작

### 3단계 워크플로우

#### Step 1: Evidence Gathering (증거 수집)
시스템이 자동으로 수집하는 데이터:

| 증거 유형 | 설명 |
|-----------|------|
| Nearby Products | 반경 내 모든 장비 제품 목록 |
| Field Notes | 해당 영역의 기존 필드 노트 |
| Terrain Stats | MOLA 경사도/고도 통계 |
| Named Regions | 인근 화성 지명 (Jezero Crater 등) |

#### Step 2: Question Input (질문 입력)
- 수집된 증거를 바탕으로 자연어 질문 입력
- 예: "이 지역에 물의 흔적이 있을 가능성은?"
- 예: "로버 착륙지로 적합한가?"

#### Step 3: Gemini Reasoning (AI 추론)
- Gemini가 증거 + 질문을 종합 분석
- Markdown 형식 답변 생성
- **Highlights** 섹션:
  - Supports (지지 증거)
  - Uncertainties (불확실성)
  - Suggested Actions (추가 조사 제안)

### 탭 구성
- **Evidence**: 수집된 증거 데이터 목록
- **Answer**: Gemini 답변 (Markdown 렌더링)
- **Products**: 관련 제품 목록 (클릭하여 Inspector 열기)
