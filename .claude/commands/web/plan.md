# Web — Plan

홈페이지/웹사이트 기획 단계. 요구사항 탐색부터 PRD 작성까지 한 번에 진행합니다.

## Instructions

### Part A: 브레인스토밍
현재 프로젝트 상태를 파악하세요:
- 기존 HTML/CSS/JS 파일이 있으면 읽고 현황 정리
- 없으면 빈 상태에서 시작

사용자에게 소크라테스식으로 질문하며 다음을 탐색:
- **목적**: 이 사이트가 해결하는 문제는 무엇인가?
- **타겟**: 누가 방문하는가? (투자자, 고객, 채용후보자, 일반대중)
- **핵심 메시지**: 방문자가 30초 안에 알아야 할 것
- **경쟁사/레퍼런스**: 벤치마킹할 사이트
- **기능 요구사항**: 다국어, 뉴스, 문의폼, 관리자 페이지 등
- **기술 제약**: 프레임워크, 호스팅, CMS 선호도

한 번에 2-3개 질문만 하세요. 사용자 답변을 기다리고, 충분히 파악되면 Part B로 진행.

### Part B: PRD 작성
`/document-skills:doc-coauthoring` 방식으로 수집된 정보를 구조화:

```markdown
# [프로젝트명] Homepage PRD

## 목표 & KPI
## 타겟 페르소나
## 사이트맵 & 페이지 구조
## 페이지별 콘텐츠 요구사항
## 디자인 방향 (톤, 레퍼런스 URL)
## 기술 스택
## 다국어 / SEO / 접근성 요구사항
## 우선순위 & 마일스톤
```

PRD를 `docs/homepage-PRD.md`에 저장하세요.
